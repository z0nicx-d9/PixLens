All notable changes to this project are documented here. The format follows

## [Unreleased]

### Added

- `pixlens` CLI: `show`, `render`, `copy`, `open`, `menu`, `overlay` and `setup`.
- Claude Code plugin: paste thumbnails above the prompt, previews under
  `Read`, `Write`, `Edit` and `Bash` steps, the `/pixlens` command and the
  `image_preview` tool.
- Pixlens Overlay: sharp pictures in Apple's Terminal and in herdr inside it,
  with hover highlights, click to open in Preview and a picture menu.
- `pixlens setup` installs the plugin into Claude Code.
- Formats: PNG, JPEG, GIF, WebP, BMP, TIFF, ICO, QOI and SVG.
